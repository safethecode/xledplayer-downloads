현재 지원하는 기능

독립적인 레이어 재생

영상 위에 이미지와 텍스트를 배치하고, 레이어마다 재생·일시정지·숨김·음소거를 제어해요.

PRV 준비하고 PGM 내보내기

미리보기에서 다음 콘텐츠를 확인하고, 명시적으로 실행할 때 출력에 반영해요.

화면별 출력 구성

스크린과 출력 영역을 드래그해 배치하고, 레이어를 개별 화면이나 여러 화면에 연결해요.

큐와 플레이리스트

미디어와 제어 명령을 큐로 묶고, 플레이리스트·스마트 폴더·스냅샷으로 공연을 준비해요.

전환과 합성

37종 전환과 30종 합성 모드, 매트 합성에 색상 효과 6종을 순서대로 조합해요.

반복 재생과 프로젝트

Soft Loop와 반복 제한을 설정하고, 프로젝트를 탭으로 열어 편집·저장·복구해요.

개발 중인 프리뷰입니다. NDI·Syphon·SDI, 라이브 입력과 Master 효과·프리셋은 아직 지원하지 않아요.

설치하기

  1. DMG 파일을 열어요.

    다운로드한 xLEDPlayer DMG를 더블 클릭하세요.

  2. 응용 프로그램으로 옮겨요.

    xLEDPlayer를 Applications 폴더로 드래그하세요.

  3. xLEDPlayer를 실행해요.

    새 프로젝트에서 미디어를 가져오고, 재생 레이어와 출력 대상을 선택하세요.

프리뷰 앱의 실행이 차단된다면

현재 프리뷰는 Apple 공증 전의 빌드예요. 신뢰할 수 있는 다운로드인지 확인한 뒤 Apple의 앱 실행 안내를 따라주세요.
